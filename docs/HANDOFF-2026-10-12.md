## The design in one paragraph each

**Defaults (ADR-010).** Every authoritative CI job is defined on main; records are validated by a scheduled job from main that advances a validated ref; invalid records land and are flagged. Stages and leases, fourteen record types, the profile bound by amendment, builder worktrees, hook rules for code-before-gate-1 and secret reads, one published npm package with a shrinkwrap, install references from release tags, a YAML runbook, keychain and 1Password as secret stores.

**Mapping resolutions (ADR-011).** Every builder in its own worktree. artifact-check and classify jobs. Pull-request classes. Defaults for 35 open items. The thirty reference mechanisms adopted explicitly. The verification register, now nineteen assumptions.

**Verification resolutions (ADR-012).** The work-only job runs the lock comparison. CODEOWNERS excludes the work zone and docs. Seven canonical layers. Citation answers need no delegation policy; open decisions do. A `rules` approval gate, three protected refs, release build from the merge commit, `migrate` in phase zero, and the register of approved decisions the design touches.

**Lock guard (ADR-013).** `lock-guard` and `class-check` on every pull request to main, default deny for unclassified branches.

**Final corrections (ADR-014).** One required merge check that dispatches by class, so GitHub's single required-check list suffices. Main's protection binds administrators. The bootstrap class is bounded by data: usable only until the first lock record exists, and only under a human bootstrap approval bound to the tree. The first-lock sequence is explicit. Release pull requests merge under a human release amendment. The authoritative dispatch is a record on the records branch; the local pointer is untracked; hook 4 denies the question tool in any secondary worktree while a dispatch is live. Doctor has a scheduled reading that fails on any waiver and a merge-blocking reading that fails only on an unwaived gap.
